# Olá, seja bem-vindo!

Me chamo Marcos, sou desenvolvedor web e estou sempre aprendendo alguma coisa nova.

Comecei a programar por curiosidade e fui continuando pela satisfação de ver algo que criei funcionando. Gosto de desenvolver projetos do zero, trabalhando desde a interface até a lógica da aplicação e o banco de dados.

Este perfil reúne alguns dos projetos que venho desenvolvendo enquanto estudo e experimento novas tecnologias.

---

## Sobre mim

Meu foco principal é desenvolvimento web. Trabalho tanto com Front-end quanto com Back-end e gosto de entender todas as partes de uma aplicação, desde a estrutura da página até a comunicação com o banco de dados.

No dia a dia, PHP é a linguagem que mais utilizo. Também trabalho com JavaScript, Python e Node.js dependendo do projeto e do que estou tentando desenvolver.

Gosto de aprender na prática. Muitas das tecnologias que conheço surgiram a partir de projetos que comecei para testar alguma ideia ou resolver algum problema.
